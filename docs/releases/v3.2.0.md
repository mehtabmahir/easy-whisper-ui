EasyWhisperUI 3.2 brings a new real-time Transcript Reader and **Local AI Summaries!** Watch your words appear, turn recordings into structured Markdown, and create summaries or custom responses right inside the app. Local language models keep processing on your computer, with unified model management, a retryable queue, and in-app updates.

## New Features!

- **Transcript reader** — read normal file transcriptions as Whisper produces new segments, without waiting for the whole recording to finish. The reader has a spacious output area, controls on the left, and a blurred background matching the rest of the app. The console continues to show raw output. Once transcription finishes, the reader uses the saved TXT output. - **AI Cleanup** — turn a completed transcript into a separate, readable Markdown document, with topic headings and shorter paragraphs. Compare the edited text with the original, navigate headings, copy text, and reveal the saved file. The original transcript remains available, and repeated runs save numbered Markdown files instead of overwriting earlier results. ## Requirements

### Windows 10/11 (64-bit)

- First-time setup downloads dependencies and builds Whisper. Allow time for the toolchain installation and compilation; the progress percentage is an estimate.
- Install current Intel / AMD / NVIDIA graphics drivers with Vulkan support for Whisper GPU acceleration.
- Required tools install automatically during setup and may request administrator approval.
- Native Acrylic background blur requires Windows 11 22H2 or newer. Older Windows versions use a solid background.
- The Whisper GPU check automatically downloads and reuses the small `tiny.en-q5_1` model (about 32 MB) when needed.

### macOS / Linux

- macOS requires Apple Silicon and macOS 13 or newer. Whisper, Metal support and FFmpeg are bundled.
- Linux support remains beta; please report distro-specific problems with logs. In-app installer updates are currently for Windows and macOS only.

### Local AI models

- Regular transcription and the transcript reader do not require a language model.
- Local AI cleanup, summaries and custom requests need a separate language model download. Once downloaded, local processing works offline without an API key or a separate model server.
- Choose a built-in model, an instruction-tuned GGUF model file, or an OpenAI / OpenAI-compatible API provider. Whisper speech models cannot be used as the cleanup language model.
- API processing sends transcript text, not audio, to the selected provider. Usage may be billed to your account. API keys are held for the current session only and must be entered again after restarting.

## Known Limitations

- AI-generated text can omit details, misunderstand technical terms, or change meaning, even when asked to remain verbatim. Review important output against the original. Smaller models are especially limited on complex recordings.
- Local AI speed and memory use vary by hardware, model and recording length. The memory indicator is an estimate, not a guarantee that a model will fit or run quickly.
- Live overlap merging is heuristic. A separate raw text capture is retained for comparison.
- Windows binaries are unsigned. (This may cause false alarms from anti-virus.)
- The macOS app is ad-hoc signed and not notarized. macOS may block it on first opening; use the steps below.
- Linux support remains beta (previously tested on Ubuntu); Linux in-app updates are not included.
- In-app updates require a published stable release with a matching installer and valid verification information. Draft and prerelease releases do not trigger the update prompt. Older public builds without the updater need a manual upgrade first.
### macOS first opening

1. **Drag `EasyWhisperUI.app` into `Applications`.**
2. Try opening it. If macOS blocks it, use **System Settings → Privacy & Security → Open Anyway** when available.
3. If it is reported as damaged and macOS offers no override, remove the download quarantine from this app only. After confirming you downloaded it from the official release, open **Terminal** and run:

```bash
sudo xattr -dr com.apple.quarantine "/Applications/EasyWhisperUI.app"
```

4. Open **EasyWhisperUI** again. This does not notarize the app or disable Gatekeeper system-wide.
